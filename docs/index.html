使用指南

  1. 选择一幅画面

    上传图片，或最长 60 秒、100 MB 内的视频。支持格式取决于浏览器解码能力。

  2. 找到它的声音

    钢琴的「短旋律」会重复开头、变化句尾。「自由扫描」逐段取音。扫描光点可在钢琴面板独立开关。图片按从左至右扫描；视频按时间抽样。亮度影响力度与滤波，色相影响音高，纹理影响音符密度，运动影响调制。

  3. 让画面自由流动

    形变默认关闭。播放时可随时开关，音频与时间轴保持连续。Time Warp 对视频使用近期帧片段，对图片使用空间扭曲。

  4. 带走你的声音

    导出当前设置下完整时长的立体声 WAV（44.1 kHz / 16-bit），包含主音量。钢琴采用合成建模，非采样钢琴。MP4 导出暂未提供。

素材不会离开浏览器；刷新页面会清除当前作品。空格播放 / 暂停；时间轴支持方向键。
